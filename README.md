# Studio for Mac

**[Download Studio for Mac](https://github.com/amywork777/studio-download/releases/latest/download/Studio-arm64.dmg)** (Apple silicon, M1 or newer)

See how Studio works, with screenshots: [studio-for-mac.vercel.app](https://studio-for-mac.vercel.app)

1. Open the download and drag Studio into Applications.
2. Open Studio. The first time, macOS stops it because it isn't from the App Store or a registered developer: open System Settings, choose Privacy & Security, and click Open Anyway beside Studio.
3. On Studio's first screen, install Claude Code and sign in with your own Claude subscription.

Studio is in early testing.
