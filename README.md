# Studio

A CAD app for Mac and Windows with AI built in. See how it works, with screenshots: [studio-for-mac.vercel.app](https://studio-for-mac.vercel.app)

## Mac

**[Download Studio for Mac](https://github.com/amywork777/studio-download/releases/latest/download/Studio-arm64.dmg)** (Apple silicon, M1 or newer)

1. Open the download and drag Studio into Applications.
2. Open Studio. The first time, macOS says it came from the internet and that Apple checked it: click Open.
3. On Studio's first screen, sign in to Claude or ChatGPT with your own subscription. Have an invite code instead? On the Codex card, choose **Use an invite code** and paste it (Studio 0.1.4 or newer).

## Windows

**[Download Studio for Windows](https://github.com/amywork777/studio-download/releases/latest/download/Studio-Setup.exe)** (Windows 10 or 11)

1. Install [Git for Windows](https://git-scm.com/downloads/win) if you don't have it, and keep the options it suggests. Studio keeps your versions with it, and the AI runs its tools in it.
2. Open the download. If Windows says it protected your PC, click More info, then Run anyway. Studio installs itself in a few minutes and opens.
3. On Studio's first screen, sign in to Claude or ChatGPT with your own subscription. Have an invite code instead? On the Codex card, choose **Use an invite code** and paste it (Studio 0.1.4 or newer).

## Updates

Studio updates itself. When a new version is out, an update button shows in its sidebar: click it to download the update, then click it again to restart. On a Mac, a copy from before 0.1.2 needs this download once.

Studio is in early testing.
